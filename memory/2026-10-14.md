# Сессии и владельцы

Auth.js обновляет JWT cookie с постоянным expires даже при cookie options без maxAge.
Для чужого устройства используем отдельный HttpOnly session nonce плюс signed expiry
8h; для личного signed absolute 90d. Browser restore может восстановить session cookies,
поэтому интерфейс рекомендует явный выход. Обновление JWT не продлевает valid_until.

Owner права отдельным DB flag, свежий read на server/API. Первичная identity из
OWNER_USER_ID защищена от снятия другим владельцем, последний владелец защищён
Serializable transaction. Bootstrap по ENV только при добавлении колонки, не каждый deploy.
