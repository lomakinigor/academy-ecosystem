# Снятие прежних административных ролей

- По прямому запросу владельца сняты PRESIDENT/VICE_PRESIDENT/BRANCH_DIRECTOR/BRANCH_ADMIN у остальных пяти аккаунтов, они стали STUDENT. Владелец исключён по проверенному ID с дополнительным EXISTS guard; пароль/бронирования/филиалы не менялись.
- Контрольный SELECT system_role <> STUDENT вернул только аккаунт владельца BRANCH_ADMIN.
- Ограничение: старые JWT на прежних deployment могут сохранять роли до истечения сессии. Полное немедленное отключение таких сессий не подтверждено; новая отдельная сборка читает права из БД.
- Ошибка 42601 при контрольном SELECT: Monaco setValue заменил только текущий сегмент длинного запроса. Исправление: фокус editor → Ctrl+A → typeText всего короткого SELECT. До Run сверять полный текст; после ошибки не повторять UPDATE.
