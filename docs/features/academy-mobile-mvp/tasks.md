# План реализации: мобильный MVP Академии

Код не начинается до подтверждения этой спецификации.

1. Добавить failing tests для прав клиентской базы и правил конфликта событий.
2. Добавить migration и Prisma-модели клиента/контактов, проверить сохранность
   существующих пользователей и бронирований.
3. Реализовать серверные операции клиентов с проверкой `BRANCH_ADMIN+`.
4. Добавить unit-тесты нормализации контактов и безопасной привязки Telegram.
5. Реализовать четыре раздела mobile-first admin-навигации и заглушки.
6. Перевести календарь на недельный вид, периодную загрузку и предупреждения
   о конфликтах; покрыть component-тестами.
7. Реализовать мобильный список и создание клиентов; покрыть RBAC и формы.
8. Добавить клиентский маршрут Telegram Mini App, серверную проверку `initData`
   и переход администратора в web-админку.
9. Прогнать typecheck, unit/integration/component tests, ручную мобильную
   проверку и e2e-путь после настройки бота.
