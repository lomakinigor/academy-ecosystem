# Подключение Telegram расписания

Цель: меню РАСПИСАНИЕ у @hdaschedulebot открывает существующий публичный web-MVP.
База, регистрация и управление остаются общими. Пользователь разрешил Mini App.

Ограничение Telegram: меню снизу доступно в чате бота; в канале нужна кнопка
в сообщении со ссылкой на настроенную Main Mini App. Main Mini App задаётся в
BotFather. Не публиковать нерабочую ссылку в канал.

Токен sensitive доступен только внутри Vercel. Однократный конфигурационный build
проверяет getMe (точное имя бота), права канала и настраивает/проверяет menu button.
Не выводит токен; не меняет webhook и не забирает updates. Отдельная конфигурация
не участвует в обычных сборках. Проверка: mock Bot API, затем серверный запуск.

Review: цель и ограничения понятны, ошибок идентичности нельзя игнорировать,
данные не меняются; отмена настройки возможна через BotFather. Следующий шаг —
проверить Main Mini App и только затем опубликовать кнопку в канале.
