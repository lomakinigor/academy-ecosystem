# Компактное публичное расписание на телефоне

## Problem statement

Публичное расписание должно быстро показывать несколько ближайших мероприятий,
а выход из админ-панели не должен оставлять администратора без точки возврата.

## User stories

- Как администратор, после возврата в публичный календарь я вижу «Админ-панель»
  и открываю рабочий раздел без новой регистрации.
- Как посетитель, я вижу в одной карточке только дату, время, название и спикера,
  а подробности открываю по желанию.

## Acceptance criteria

- «Админ-панель» отображается на мобильном экране публичной части для
  авторизованного администратора; ссылка ведёт на `/admin/calendar`.
- Закрытая компактная карточка содержит дату, время (либо «Весь день»), название
  и спикера.
- Описание, место, стоимость, формат, теги и ссылка на полную карточку находятся
  внутри `<details>` с текстом «Подробнее».
- Компактный режим используется только на публичной странице; админские и
  студенческие карточки не меняются.
- Нет изменений API, базы, ролей и данных мероприятий.

## Проверка и откат

Component tests проверяют мобильную ссылку в админку и структуру компактной
карточки. Existing agenda tests подтверждают группировку и многодневные даты.
Откат: убрать `compact` из публичного `AgendaList` и вернуть старую точку
встраивания ссылки; данные не затрагиваются.
