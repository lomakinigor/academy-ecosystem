# Мобильное публичное расписание — brainstorming

1. **Проблема.** После выхода из админ-панели администратор не видит путь назад
   на телефоне. Публичные карточки мероприятий занимают слишком много места.
2. **Текущее поведение.** Ссылка в админку скрыта ниже `sm`; карточка выводит
   тип, теги, описание, место, стоимость и заполненность сразу.
3. **Целевое поведение.** На телефоне администратор видит текстовую
   «Админ-панель». Публичная карточка в закрытом виде показывает только дату,
   время, название и спикера; прочее раскрывается по «Подробнее».
4. **Ограничения.** Нет изменений базы, ролей и Mini App. Закрытый маршрут
   `/admin/calendar` остаётся единственным местом проверки прав.
5. **Альтернативы.** Полная отдельная мобильная страница потребовала бы дублировать
   календарную логику. Выбран компактный вариант существующей карточки только для
   публичной страницы.
6. **Риски.** Меньшая карточка может скрывать длинное название. Используем
   `line-clamp`, а полное название останется доступным в раскрытии и на странице
   мероприятия.
