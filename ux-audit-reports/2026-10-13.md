# Pre-release проверка web-MVP

## Границы

Проверены исходники главной, signup, клиентов/назначения администраторов, недельного календаря и состояния недоступности. Полная шкала `~/.Codex/quality-principles-reference.md` отсутствует на хосте. Поэтому численные оценки по 27 критериям не выставляются: их нельзя подтвердить по утверждённой шкале. Релизный gate **не пройден**, основной домен не переключаем.

## Блокирующие замечания

1. Signup автоматически активирует ручную карточку по совпадению непроверенного email. Требуется подтверждение владения или безопасный отдельный сценарий связывания.
2. Недельный календарь min-width 840px требует внутренней горизонтальной прокрутки на телефоне; удобство ещё не подтверждено ручным сценарным тестом.
3. Пакетная форма — широкая таблица; редактирование каждого поля на 360px ещё не проверено.
4. Не проверен весь авторизованный flow владельца на отдельном домене: пользователь вводит пароль самостоятельно.
5. Публичная страница продолжает показывать филиальные фильтры; нужно согласовать с режимом общей базы и будущими филиалами.

## Что работает по коду

- Расписание публичное; регистрация требуется для записи.
- Ошибка БД не обрушивает публичную страницу.
- Вход/регистрация имеют кнопку видимости пароля.
- Четыре раздела админки сохранены, управление админами внутри клиентов.
- Настройка владельца fail closed, самоснятие запрещено, права перечитываются из БД.

## Решение

Разрешена только отдельная проверочная сборка для владельца, не релиз завершённого MVP. Проверка skill `ux-audit` остановила назначение новой сборки основному домену. Требуются безопасная регистрация, мобильная проверка и доступ к полной шкале либо её согласованная замена.

## Проверочная сборка рабочих мероприятий

По разрешению владельца включает responsive weekly-calendar и batch review, статус владельца вместо учебного badge, active nav с aria-current и прямые CTA ручного/пакетного ввода. Все 144 web-теста и TypeScript прошли. Ручная карточка остаётся вариантом для согласования; существующие поля сохранены, обязательность не расширена. Публичный релизный gate по-прежнему не пройден; разрешение относится только к отдельной сборке для просмотра. Browser review авторизованных экранов нужно повторить после входа владельца на новый домен.
